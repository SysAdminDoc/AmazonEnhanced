# AmazonEnhanced marketing review

This folder preserves the original source and artwork from commit `12b830c7925622a63bb551bb096707dfe0f4ed5f`, before the v2.0.18 marketing pass.

`originals-index.json` records all 100 original files and their SHA-256 digests. It sits outside `originals/` because that directory already contains the extension's real `manifest.json`.

The existing blue/green shield is retained. The unrelated product photograph in the original tree isn't a proposed logo. No replacement artwork was generated for this pass. Settings captures come from the installed extension in isolated profiles, not a mocked interface or a signed-in shopping account.

Review captures and selection notes are retained here. Historical installer packages are backed up privately; signing keys and local shopping-page archives are never copied into this public folder.

## Review record

- `baseline/` keeps the prior settings capture and the initial wrong-worker diagnostic. The error page isn't product marketing.
- `settings-r1/` records a worker-startup timing failure. Its public log uses relative review paths; the original machine-path log is retained privately.
- `settings-r2/` and `settings-r3/` retain all ten settings sections, long-panel scroll positions and theme checks. The final set runs from the exact release ZIP's extracted bytes.
- `sidepanel-r1/` shows the inherited layout bug. `sidepanel-r2/` and `sidepanel-r3/` retain its repaired layout, saved-theme checks, narrow view and empty alerts. Price histories are invented test data.
- `visual-review/` compares the unchanged icon on light and dark backgrounds and shows the complete settings overview.
- `readme-review-r1/` and `readme-review-r2/` contain GitHub-rendered Markdown in a local review stylesheet. They aren't live GitHub page screenshots.

`selection.json` identifies the chosen assets by hash. Readable settings and direct installation guidance replace the earlier screenshot-free feature list. The existing logo remains selected; no speculative replacement is presented as an improvement.
